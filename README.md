# 🎓 RelaxU – Stress Monitoring & Workload Management Web App

RelaxU is a web application designed to help university students monitor stress levels and manage academic workload efficiently. Built using **core technologies (HTML, CSS, JavaScript, PHP)** without frameworks, RelaxU provides interactive tools to assess stress, access relaxation techniques, manage academic tasks, and engage in community support.

This system is structured using the **MVC pattern** (Model, View, Controller) with no routing frameworks.

---

## 🚀 Key Features

### 🧠 1. Stress Monitoring and Assessment
- Self-assessment questionnaire and typing test for stress detection
- Backend algorithm to determine stress level (High / Moderate / Low)
- Real-time insights for personalized feedback

### 🌿 2. Personalized Stress Management
- Guided meditations, mindfulness activities, and breathing exercises
- Redirection to counseling for high stress levels
- Seamless integration into daily schedules

### 📚 3. Academic & Time Management
- Task creation, reminders, deadline setting
- Productivity analytics and goal tracking
- Efficient coordination with lecturers and advisors

### 🤝 4. Peer Support & Community
- Community forums for academic and emotional support
- Virtual support groups, event hosting, and peer connections

### 🧾 5. Educational Resources & Counseling
- Articles, videos, and mental health content
- Appointment booking with counselors and lecturers

### 🔄 6. Continuous Feedback & Improvement
- User feedback integration for iterative upgrades
- System evolves with research and student needs

---

## ⚙️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP (MVC architecture, no framework)
- **Database**: MySQL (relaxu.sql)
- **Icons**: Font Awesome CDN
